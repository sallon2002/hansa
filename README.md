# 한국사 1급 문제 풀이

한국사능력검정 심화(1급) 대비 문제 사이트. 구석기부터 노무현 정부까지,
시험에 자주 나오는 시대 비중대로 랜덤 출제한다. 탭이 둘이다.

- **개념 문제**: "삼별초의 기원인 야별초를 조직한 무신 집권자는?" 식의 짧은 4지선다. 858문항.
- **실전 문제**: 한능검 심화 기출 유형 그대로. 자료(사료·대화·안내문·신문·일기·연표·검색·묶음) 한 편을 읽고
  5지선다. 보기 다섯은 모두 실제 사실이고 자료와 맞는 하나만 정답. 배점 1·2·3점.

## 여는 법

- **내 컴퓨터에서**: `index.html` 을 더블클릭하면 브라우저에서 바로 열린다. 설치할 것 없음.
- **인터넷 주소**: https://sallon2002.github.io/hansa/ (GitHub Pages, 저장소 github.com/sallon2002/hansa).
  고친 내용은 커밋 후 `git push` 하면 1~2분 뒤 이 주소에 반영된다.
- **아이폰·아이패드 앱처럼 쓰기**: 사파리로 위 주소를 열고 공유 버튼 → 「홈 화면에 추가」.
  금빛 「史」 아이콘이 생기고, 누르면 주소창 없이 전체 화면으로 열린다(`manifest.webmanifest`, `icons/`).
- **다른 곳에 올리기**: 이 폴더 통째로(`index.html`, `styles.css`, `app.js`, `data/`) 아무 웹 호스팅에 올리면 된다.
  서버 프로그램이 필요 없는 정적 사이트라 카페24 · GitHub Pages · Netlify 어디든 된다.

## 푸는 법

- `1`~`4` 키 또는 클릭으로 고른다.
- 고르는 순간 네 보기 모두 밑에 설명이 붙는다(정답 보기엔 해설, 오답 보기엔 왜 틀렸는지).
- `Enter` 로 다음 문제. 휴대폰·아이패드에선 답을 고르면 화면 아래에 **다음 문제** 버튼이 붙는다.
- 컴퓨터 · 아이패드(가로·세로) · 휴대폰 화면에 맞춰 배치가 바뀐다.
- 위쪽 **오답 노트** 탭: 틀린 문제만 다시. 다시 맞히면 목록에서 빠진다.
- 오답 노트 문제는 전체 랜덤에서도 일반 문제보다 약 1.2배 자주 나온다(티 나지 않게). 맞히면 노트에서 빠진다.
- 푼 기록은 그 브라우저에만 저장된다. 다른 기기로는 기록 칸의 「기록 옮기기」로 코드를 복사해 붙여 넣어 옮긴다.

## 실전 문제 추가

`data/exam/<시대>.js` 에 한 줄 = 문제 하나(JSON 객체). 형식은 `tools/check-exam.js` 머리 주석에 있다.
형식 검사: `node tools/check-exam.js`. 대량으로 쓸 때는 `work/exam/*.json` 에 쓰고 `node tools/exam-merge.js` 로 합친다.
검증 결과 반영은 `work/exam-fix/<시대>.json` → `node tools/exam-fix.js show` 로 보고 `apply` 로 반영.

## 출제 비중

`data/eras.js` 의 `weight` — 심화 50문항 중 그 시대에서 보통 나오는 문항 수.
시대를 이 비중으로 먼저 고르고, 그 시대 안에서 아직 안 낸 문제부터 낸다.

## 문제 추가

`data/<시대>.js` 맨 아래에 한 줄씩 덧붙인다.

```js
["문제", "정답", "오답1", "오답2", "오답3", "해설", "오답1 — 왜 아닌지", "오답2 — 왜 아닌지", "오답3 — 왜 아닌지"],
```

정답은 늘 두 번째 칸. 보기 순서는 화면이 섞는다.
해설은 정답 보기 밑에, 뒤의 세 칸(오답 풀이)은 각 오답 보기 밑에 붙는다. "보기 이름 — 설명" 꼴로 쓰면 화면에서는 설명만 보인다.
줄 순서가 문제 번호라(오답 노트가 기억함) 중간에 끼우거나 지우지 말 것.

형식 검사: `node tools/check.js` (칸 수 · 보기 중복 · 문제 중복)
