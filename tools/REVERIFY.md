# 한국사 문제 전수 재검증 (2026-10-31)

사이트에 이미 올라가 있는 문제다. 오답 노트가 줄 번호(0부터)를 기억하므로 **문제를 빼거나 순서를 바꾸지 않는다** — 그 자리에서 고치기만 한다.

## 개념 문제 (data/<시대>.js, 한 줄 = [문제, 정답, 오답1~3, 해설, 오답1~3 풀이])
확인: 문제·정답·해설이 사실인가 / 오답 셋이 정말 틀렸고 정답으로 볼 여지가 없는가 / 오답 풀이가 그 오답을 정확히 설명하는가 /
문제 문장에 정답이 드러나지 않는가 / 범위(구석기~노무현 정부)·난이도가 「짧은 개념 확인」에 맞는가.
고칠 문제는 `work/concept-fix/<시대>.json` 에 `{"fixes":[{"i":줄번호,"row":[9칸 전체],"reason":"..."}]}` 로 쓴다(data 파일은 직접 고치지 않는다).
`node tools/concept-fix.js show` 로 내 파일이 제대로 읽히는지 확인만 한다(apply 는 하지 않는다 — 다른 검증자 것과 한꺼번에 적용한다).

## 실전 문제 (data/exam/<시대>.js, 한 줄 = 객체, 형식은 tools/check-exam.js 머리 주석)
확인: 자료 내용·보기 다섯·notes 다섯이 사실인가 / 자료가 가리키는 대상이 분명하고 정답이 하나뿐인가(오답이 정답 대상에도 맞는 함정) /
연표 구간 경계 연도 / 자료·alt 에 답이 드러나지 않는가 / **사진**: image.src(images/...)를 Read 로 직접 열어 그 문화유산·인물·장면이 맞는지,
화질이 쓸 만한지, 글자로 답이 드러나지 않는지, credit·page 가 맞는지(필요하면 `node tools/commons.js`… 는 없으니 page URL 의 파일 이름으로 판단).
고칠 문제는 `work/exam-fix/<시대>.json` 에 `{"fixes":[{"i":줄번호,"q":{고친 문제 전체},"reason":"..."}]}` (remove 는 쓰지 않는다).
사진을 바꿔야 하면 바꾸지 말고 reason 에 「사진 교체 필요: 이유」로 적고 q 는 사진 그대로 둔 채 다른 수정만 넣는다(사진은 따로 처리).
`node tools/exam-fix.js show` 로 읽히는지만 확인(apply 하지 않는다).

명령은 C:\KOREAN-HISTORY 에서 Bash 로, node 는 "/c/Program Files/nodejs/node.exe".
