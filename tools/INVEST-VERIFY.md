# 투자자산운용사 문제 검증 안내 (검증자용)

맡은 세부과목의 작업 파일(work/invest/concept-<id>.json · exam-<id>.json)을 한 문제씩 검증하고, 틀린 것은 **그 파일을 직접 고친다.**
작성 원칙은 tools/INVEST-WRITING.md.

## 문제마다 확인할 것

1. **사실·정의**: 정답·오답·해설·오답 풀이가 협회 기본서 기준으로 맞는가. 용어가 정확한가.
2. **정답이 하나뿐인가**: 오답 보기 중 정답으로도 볼 수 있는 것이 없는가. "옳지 않은 것" 문제면 틀린 보기가 정확히 하나인가.
3. **계산**: 모든 계산 문제를 직접 다시 풀고(node 로 계산해 확인), 정답 보기와 notes 의 계산 과정·숫자가 맞는지. 반올림 때문에 보기 둘이 정답이 될 여지가 없는지.
4. **법규·세제의 현행성**: 2026년 현행 기준으로 맞는가. 확실하지 않거나 최근 개정으로 바뀌었을 수 있는 수치·제도면, 원리를 묻는 문제로 바꾸거나 그 문제를 같은 세부과목의 다른 확실한 문제로 교체한다.
5. **답이 문제에 드러나지 않는가**, 해설이 엉뚱하지 않은가, 같은 파일 안에 거의 같은 문제가 겹치지 않는가.

## 고칠 때

- 문항 수는 그대로 둔다(빼면 같은 수만큼 새로 쓴다). 실전 정답 위치(0~3)는 대략 고르게.
- 다 고친 뒤 `"/c/Program Files/nodejs/node.exe" tools/check-invest.js <파일>` 이 ✓ 이상 없음.
- 고친 내역을 `work/invest/fix-<id>.md` 에 "파일#번호 — 무엇이 문제였고 어떻게 고쳤는지" 한 줄씩 (없으면 "수정 없음").
- 맡은 파일 말고는 고치지 않는다. 명령은 C:\KOREAN-HISTORY 에서 Bash 로.
