# 한국사 1급 문제 풀이

한국사능력검정 심화(1급) 대비용 개념 객관식 문제 사이트. 구석기부터 노무현 정부까지,
시험에 자주 나오는 시대 비중대로 랜덤 출제한다.

## 여는 법

- **내 컴퓨터에서**: `index.html` 을 더블클릭하면 브라우저에서 바로 열린다. 설치할 것 없음.
- **인터넷에 올리기**: 이 폴더 통째로(`index.html`, `styles.css`, `app.js`, `data/`) 아무 웹 호스팅에 올리면 된다.
  서버 프로그램이 필요 없는 정적 사이트라 카페24 · GitHub Pages · Netlify 어디든 된다.

## 푸는 법

- `1`~`4` 키 또는 클릭으로 고른다.
- 오답이면 오른쪽에 정답과 해설, 정답이면 체크 표시만.
- `Enter` 로 다음 문제.
- 위쪽 **오답 노트** 탭: 틀린 문제만 다시. 다시 맞히면 목록에서 빠진다.
- 푼 기록은 그 브라우저에만 저장된다(다른 기기와 공유되지 않음).

## 출제 비중

`data/eras.js` 의 `weight` — 심화 50문항 중 그 시대에서 보통 나오는 문항 수.
시대를 이 비중으로 먼저 고르고, 그 시대 안에서 아직 안 낸 문제부터 낸다.

## 문제 추가

`data/<시대>.js` 맨 아래에 한 줄씩 덧붙인다.

```js
["문제", "정답", "오답", "오답", "오답", "해설"],
```

정답은 늘 두 번째 칸. 보기 순서는 화면이 섞는다.
줄 순서가 문제 번호라(오답 노트가 기억함) 중간에 끼우거나 지우지 말 것.

형식 검사: `node tools/check.js` (칸 수 · 보기 중복 · 문제 중복)
