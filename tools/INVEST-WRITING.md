# 투자자산운용사 문제 쓰는 법 (작성자 안내)

사이트 「탈기술원을 향하여」의 **투자자산운용사** 과목 문제를 새로 쓴다. 금융투자협회는 시험 문제를 공개하지 않으므로
기출을 옮기지 않고, 시험 출제 범위(협회 기본서 체계)와 자주 나오는 개념을 바탕으로 **처음부터 새로 쓴다**.
수험서·학원 문제집·복원 기출의 문장을 베끼지 않는다.

세부과목 목록과 비중: `data/invest/eras.js` (id · label · weight). 당신은 맡은 세부과목(들)의 문제를 쓴다.

## 1. 개념 문제 (`work/invest/concept-<id>.json`)

한 문제 = 9칸 배열. **4지선다**(정답 1 + 오답 3).
```json
["문제", "정답", "오답1", "오답2", "오답3", "해설(정답이 왜 맞는지)", "오답1 — 왜 아닌지", "오답2 — 왜 아닌지", "오답3 — 왜 아닌지"]
```
- 짧은 개념 확인형: "듀레이션에 대한 설명으로 옳은 것은?"보다는 더 짧게 — 예) "만기가 길수록, 표면이자율이 낮을수록 길어지는 채권 지표는?" / "VaR 를 95% 신뢰수준에서 99% 로 바꾸면 VaR 는?"
- 정답은 늘 2번째 칸(화면이 섞는다). 오답 셋은 같은 범주의 그럴듯한 다른 개념.
- 해설·오답 풀이는 한두 문장. 오답 풀이는 "오답 이름 — 설명" 꼴.
- 간단한 계산도 섞는다(개념의 15~20% 정도): 예) "액면 10,000원, 표면이율 5%, 만기 1년 채권의 시장수익률이 4% 일 때 가격에 가장 가까운 것은?"

## 2. 실전 문제 (`work/invest/exam-<id>.json`)

실제 시험처럼 4지선다. 한 문제 = 객체.
```json
{"era": "bond", "stem": "다음 중 듀레이션에 대한 설명으로 옳지 않은 것은?",
 "source": {"kind": "지문", "title": "(없으면 생략)", "text": "지문·사례·조건 (없으면 source 자체를 생략)"},
 "choices": ["...", "...", "...", "..."], "answer": 2,
 "notes": ["보기마다 왜 맞고 왜 틀린지", "...", "...", "..."], "fixed": true}
```
- 물음 꼴은 실제 시험처럼: "~에 대한 설명으로 옳은 것은? / 옳지 않은 것은?", "~에 해당하는 것을 모두 고른 것은?"(ㄱ·ㄴ·ㄷ·ㄹ 지문 + 보기 "ㄱ, ㄴ" 꼴), 계산형 "~의 값은?".
- **계산 문제는 실전의 25~35%** (투자분석기법·리스크관리·채권·파생·투자운용결과분석·분산투자 같은 계량 과목은 더 많이, 법규·윤리·세제는 적게). 숫자는 손으로 풀 수 있게 깔끔하게. 정답 계산을 notes 에 단계별로 보인다.
- 표가 필요하면 `"kind": "표"` 로 하고 text 에 한 줄 = 한 행, 칸은 ` | ` 로 나눈다(첫 줄이 머리글).
  예) `"구분 | 기대수익률 | 표준편차\nA | 10% | 20%\nB | 8% | 12%"`
- 보기 순서가 뜻을 가지면(숫자 오름차순, "ㄱ, ㄴ" 조합) `"fixed": true` — 화면이 섞지 않는다. 숫자 보기는 오름차순으로.
- notes 4칸: 정답 칸은 근거(계산 과정 포함), 나머지는 왜 틀렸는지.

## 3. 정확성 (가장 중요)

- 모든 보기·해설이 사실이어야 하고 정답은 **하나뿐**이어야 한다. "옳지 않은 것" 문제면 틀린 보기가 정확히 하나.
- 계산은 두 번 검산한다(작은 스크립트로 계산해 봐도 좋다).
- **법규·세제는 개정이 잦다.** 확실한 현행(2026년) 내용만 쓴다. 최근 바뀐 수치·제도(예: 금융투자소득세는 시행 전 폐지됨)나
  기억이 확실치 않은 금액·비율·기간은 문제로 내지 말고 원리·구조를 묻는다.
- 용어는 협회 기본서에서 쓰는 한국어 용어(예: 듀레이션, 볼록성, 샤프비율, 젠센의 알파, 정보비율, VaR, 베이시스, 콘탱고).
