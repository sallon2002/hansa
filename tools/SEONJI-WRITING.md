# 선지 선별 문제 쓰기

사용자가 가진 한능검 선택지 노트(PDF)의 「공부 내용 확인」(빈칸 채우기) 문항을 4지선다로 옮긴다.
사이트는 공개되어 있으므로 **책 문장을 그대로 옮기지 않는다**. 묻는 사실과 정답은 책과 같게 두고, 설명 문장은 우리 말로 바꿔 쓴다.
책에 사실 오류가 있으면 바로잡는다(바로잡은 문항은 note 에 적는다).

## 원본
- 페이지 그림: 작업 지시에 적힌 폴더의 `pageNN.png` (NN = PDF 쪽 번호). Read 로 열어 본다(텍스트 추출은 깨져서 쓰지 않는다).
- 단원마다 「공부 내용 확인!(빈칸에 해당하는 내용을 적어보자)」 쪽과 그 뒤 「<정답>」 쪽이 있다. 앞쪽 설명 쪽은 참고만 한다.
- 「공부 내용 확인」의 **모든 문항**을 하나도 빼지 않고 옮긴다(순서 맞추기 문항 포함). 같은 사실이 두 번 나와도 각각 만든다(문장은 달리).

## 한 문항 = 9칸 (개념 문제와 같은 형식)
`[문제, 정답, 오답1, 오답2, 오답3, 해설, 오답1 풀이, 오답2 풀이, 오답3 풀이]`
- 문제: 첫 줄은 바꿔 쓴 설명 한 문장, 줄바꿈(`\n`) 뒤 둘째 줄은 묻는 말. 예
  `"벼를 거둘 때 반달 모양의 돌칼을 썼다.\n이 설명에 해당하는 시대는?"`
  묻는 말은 책이 묻는 종류에 맞춘다: 시대는? / 나라는? / 왕은? / 인물은? / 기구는? / 조약은? / 정부는? / 단체는? / 시기는? …
- 문장에 정답 이름이 드러나면 안 된다(책 문장에 들어 있으면 빼거나 돌려 말한다).
- 정답: 책 <정답> 과 같은 대상. 보기 글은 짧게(「청동기 시대」, 「광개토 대왕」, 「1920년대」, 「김영삼 정부」).
- 오답 셋: 같은 종류의 그럴듯한 대상(같은 시대 다른 왕, 이웃 나라, 앞뒤 정부 등). **설명에 정말 맞지 않아야 한다** — 같은 일을 한 다른 왕·나라가 있으면 그 대상은 오답으로 쓰지 않는다.
- 정답이 둘인 문항(예: 「국가 2개」)은 보기를 짝으로 만든다: 「옥저·동예」 vs 「부여·고구려」 ….
- 순서 맞추기 문항: 문제에 사건을 ㉠㉡㉢㉣(다섯 개 이상이면 ㉠~ 그대로) 로 줄마다 적고, 보기는 「㉡→㉠→㉣→㉢」 같은 순서 넷. 정답 순서는 책 정답과 같게, 오답 순서는 그럴듯하게. 책 사건이 많으면(6개 이상) 4~5개만 골라 한 문항으로 만들어도 되지만, 남는 사건으로 문항을 하나 더 만들어 빠지는 사건이 없게 한다.
  ㉠ 같은 기호는 써도 되지만 (가)(나) 꼴 괄호 한 글자는 쓰지 않는다(화면이 빨간 빈칸 표시로 바꾼다).
- 해설: 정답이 왜 맞는지 1~2문장(연도·핵심 키워드 포함).
- 오답 풀이: `"오답 이름 — 왜 아닌지 + 그 대상의 대표 업적·특징 한 가지"` 한 문장. 앞부분은 보기 글과 똑같이 쓴다.
- 존댓말 아닌 평서체(…했다/…이다). 범위·용어는 한능검 심화 교과서식 표기(띄어쓰기: 광개토 대왕, 흥선 대원군, 6·25 전쟁).

## 시대(era) 나누기 — 사이트 시대 id
prehistory(구석기~철기) · gojoseon(고조선~삼한) · three(삼국·가야) · nambuk(통일 신라·발해·후삼국) · goryeo ·
joseon1(건국~임진왜란, 선조까지) · joseon2(광해군~철종) · modern(흥선 대원군~국권 피탈) · colonial(1910~1945) · contemporary(광복~)
문항마다 그 내용이 속한 시대로 넣는다. 조선 단원의 정치 기구·제도처럼 시대를 가르기 어려우면 그 제도가 생긴 시기로.

## 결과 파일
`work/seonji/<단원>.json` (UTF-8):
```json
{ "unit": "1", "items": [
  { "src": "p5 선사 (6)", "era": "prehistory", "row": [9칸], "note": "선택: 책 내용을 바로잡았으면 이유" }
] }
```
- `src` = 원본 쪽·소제목·문항 번호(빠짐 확인용). 책 순서대로.
- 다 쓰면 `"/c/Program Files/nodejs/node.exe" tools/seonji-merge.js check work/seonji/<단원>.json` 로 형식을 확인한다(오류 0까지).
- data 파일은 직접 만들지 않는다(merge 는 따로 돌린다).
