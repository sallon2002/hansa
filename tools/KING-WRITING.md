# 왕 맞추기 데이터 쓰기

화면: 「고구려 광개토 대왕의 업적으로 옳은 것은?」 / 「…업적이 아닌 것은?」 4지선다.
보기는 **화면이 그때그때 고른다**: 그 왕의 업적 문장 + 다른 왕(같은 나라 먼저)의 업적 문장. 해설도 자동(「○○왕 때의 일이다」).
그래서 데이터의 핵심 규칙은 하나: **각 업적 문장은 그 왕에게만 맞아야 한다.** 다른 왕도 한 일(예: 여러 왕이 평양 공격, 여러 정부가 남북 정상 회담)이면 문장을 좁히거나(연도·상대·구체 명칭) 빼라.

## 원본
사용자의 한능검 선택지 노트 PDF 쪽 그림 `pageNN.png`(작업 지시의 폴더). 「시험에는 이렇게 나온다」 쪽의 왕별 선지가 재료다. **책 문장을 그대로 옮기지 말고 우리 말로 바꿔 쓴다**(내용·사실은 같게). 한능검 심화에 자주 나오는데 책에 빠진 대표 업적은 보태도 된다.

## 결과 파일 `work/king/<part>.json` (UTF-8)
```json
{ "kings": [
  { "id": "gwanggaeto", "nation": "고구려", "name": "광개토 대왕", "era": "three",
    "deeds": ["영락이라는 연호를 썼다.", "신라에 침입한 왜를 물리치려고 군대를 보냈다.", "..."] }
] }
```
- `id`: 영문 소문자·숫자·하이픈, 전체에서 겹치지 않게(나라 접두 권장: goguryeo-sosurim). 한 번 정하면 바꾸지 않는다.
- `nation`: 고구려 · 백제 · 신라 · 가야 · 통일 신라 · 발해 · 고려 · 조선 (후삼국 견훤·궁예는 넣지 않는다).
- `name`: 교과서식(광개토 대왕, 근초고왕, 태종 무열왕, 태조 왕건, 세종). 같은 이름(고려 태조/조선 태조, 고려 성종/조선 성종)은 nation 으로 구분되니 name 은 그대로.
- `era`: three(삼국·가야) · nambuk(통일 신라·발해) · goryeo · joseon1(태조~선조) · joseon2(광해군~고종 즉위 전, 철종까지).
- `deeds`: 한 문장씩, 평서체(…했다/…였다). **왕 이름·묘호를 문장에 넣지 않는다**(답이 드러남). 인물 이름(을지문덕, 이사부 등)은 괜찮다. 3~8개, 가능하면 4개 이상. 대표 업적 위주.
- 같은 나라 안에서 문장이 서로 헷갈리지 않게(같은 기구·제도를 두 왕에 쓰지 말 것 — 설치/정비/완성처럼 구분되면 그 말을 꼭 넣는다).

다 쓰면 `"/c/Program Files/nodejs/node.exe" tools/king-merge.js check work/king/<part>.json` 로 형식 확인(오류 0).
